# Design System — Nocturnal Pulse

## Palette
* **`bg-void` (`#0D0B14`):** Base map & screen canvas.
* **`bg-ink` (`#17131F`):** Cards, bottom sheets, navigation bars.
* **`bg-ink-raised` (`#211C2E`):** Raised surfaces & active states.
* **`border-hairline` (`#2C2739`):** 1px structural borders.
* **`signal-violet` (`#7B2FF7` / `#D2BBFF`):** Action buttons, verified badges, active chips.
* **`pulse-lilac` (`#C77DFF` / `#E1B6FF`):** Live/fresh pin glow, positive highlights.
* **`ember` (`#FF6B5E` / `#FFB4AB`):** Urgency (<30 min TTL left), warnings.
* **`text-moonlight` (`#F5F0FF`):** Primary text.
* **`text-dusk` (`#A99BC2`):** Secondary text.

## Typography
* **Display / Headlines:** Bricolage Grotesque / Clash Display
* **Body:** General Sans
* **Mono Data:** JetBrains Mono (Tabular numerals for distance, timers, and trust scores).
